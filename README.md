# Book Club

Meeting guides for our book club: agenda, chapter recaps, discussion questions and more.

**Open the guides:** https://rico9267.github.io/bookclub/

No account or sign-in needed. Open the link in any browser.

---

## For the host: updating the site

Guides are written and edited in the private planner in Claude. This site is a read-only copy.

After you save or edit a meeting in the planner, update the site one of two ways:

**Option A: ask Claude.** In a Claude chat, say "update the book club site." Claude rebuilds the page from the planner and pushes it here.

**Option B: upload it yourself (computer).**
1. In the planner, open **Saved meetings** and tap **Download public page**. You get `index.html`.
2. In this repository on GitHub, choose **Add file → Upload files**, drop in `index.html`, and commit.
3. The site updates within a minute or two.

The public copy leaves out the host's private notes about the group.

# Book Club

Meeting guides, schedule and bookshelf for our book club.

**Open it:** https://rico9267.github.io/bookclub/

No account or sign-in needed. Works in any browser, on phone or computer.

What's on the page:
- **This meeting:** the agenda, chapter recaps, discussion questions and more, plus RSVP and Add to calendar buttons for upcoming meetings. Use the spoiler shield if you're behind on the reading.
- **Schedule:** every meeting for the book, what's done and what's next.
- **Bookshelf:** what we're reading, what's up next, the books we've finished with the club's ratings, and a link to vote on the next book.

---

## For the host

Guides are written and edited in the private planner in Claude. This site is a read-only copy that updates automatically six times a day, 8:37 AM to 11:37 PM Eastern (see [SYNC.md](SYNC.md)). For an immediate update, ask Claude to "update the book club site."

`tools/sync.py` rebuilds the page from the planner's sync copy; `data/club.json` is the data currently on the site.
